# Blender Work preview artwork

One preview was created with the built-in image-generation tool, each using a rendered view of its actual GLB model as a geometry and appearance reference. They are photographic interpretations; the interactive inspector always shows the original file.

The current preview (November 2026) is a 1672 × 941 poster supplied by Manoj: the robot arm in a dark factory with the title, tagline and Unreal Engine / Blender marks. It is exported as `-1536.webp` and `-768.webp` (WebP, quality 80–82); there is no 4K export, because upscaling would add bytes but no detail. `image-sizes.json` records dimensions and byte sizes. The prompt below produced the earlier ivory-studio preview.

## Prompts

### industrial-robot-arm

Use the attached rendered 3D model as the strict identity and geometry reference. Create an ultra-realistic premium product photograph of this exact compact white articulated industrial robot arm, dark graphite bolted base, white joints and links, exposed black cable loop, gray parallel gripper, exactly the pose and geometry in the reference. Preserve silhouette, proportions, component arrangement, colors, details and text present on the asset; do not redesign or add features. Improve only material realism, lighting and photographic presentation: fine realistic surface texture, brushed metal/paint/rubber as appropriate, large softbox studio lighting, gentle natural contact shadow, clean warm ivory seamless studio floor and backdrop matching #fcfaf7, slightly warm highlights. Entire object fully visible in a refined three-quarter view, centered, camera close enough to occupy about 70 percent of the image width or height, generous breathing room, no crop. Landscape 16:9 composition suitable for a portfolio card, high-resolution/4K-quality detail. No extra props, no people, no headline, no overlay captions, no watermark. Retain logos/markings already present in reference only. This is the industrial-robot-arm asset preview; exact resemblance to provided model is more important than adding detail.
